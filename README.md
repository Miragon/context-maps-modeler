# Context Maps Modeler has moved

> [!IMPORTANT]
> This repository is archived and read-only. The Context Maps Modeler now lives in the
> [Miragon modeler suite](https://github.com/Miragon/modeler-suite), in
> [`modelers/context-maps`](https://github.com/Miragon/modeler-suite/tree/main/modelers/context-maps), with its full git history.

Nothing changes for users:

- **npm packages** keep their names and version lines; new releases come from the suite: [`@miragon/context-maps-schema-model`](https://www.npmjs.com/package/@miragon/context-maps-schema-model), [`@miragon/context-maps-cml`](https://www.npmjs.com/package/@miragon/context-maps-cml), [`@miragon/context-maps-renderer`](https://www.npmjs.com/package/@miragon/context-maps-renderer).
- **VS Code extension** `miragon-gmbh.context-maps-modeler` stays the same ([Marketplace](https://marketplace.visualstudio.com/items?itemName=miragon-gmbh.context-maps-modeler), [Open VSX](https://open-vsx.org/extension/miragon-gmbh/context-maps-modeler)).
- **Web app** stays at [context-maps.modeler.miragon.io](https://context-maps.modeler.miragon.io).

**Issues and pull requests** go to [Miragon/modeler-suite](https://github.com/Miragon/modeler-suite/issues); the open issues of
this repository were moved there. Development, CI and releases are described in the suite's
[README](https://github.com/Miragon/modeler-suite#readme) and [CONTRIBUTING.md](https://github.com/Miragon/modeler-suite/blob/main/CONTRIBUTING.md), the
modeler itself in [`modelers/context-maps/README.md`](https://github.com/Miragon/modeler-suite/blob/main/modelers/context-maps/README.md).
